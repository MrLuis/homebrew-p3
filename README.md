# Mrluis P3

## How do I install these formulae?

`brew install mrluis/p3/<formula>`

Or `brew tap mrluis/p3` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mrluis/p3"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
